# نسخه نصب‌شونده هم‌گام (PWA)

این پوشه نسخه نصب‌شونده برنامه است. فایل اصلی single-file شما در مسیر قبلی دست‌نخورده باقی مانده است.

## فایل‌ها

- `index.html` برنامه اصلی نصب‌شونده
- `manifest.webmanifest` مشخصات نصب برنامه
- `sw.js` سرویس‌ورکر برای کار آفلاین پس از نصب
- `icons/` آیکن‌های برنامه

## نکته مهم

PWA از روی `file://` به‌شکل کامل نصب نمی‌شود، چون مرورگر برای Service Worker آدرس امن می‌خواهد.
برای نصب واقعی باید برنامه یک بار از یکی از این حالت‌ها باز شود:

1. `localhost` روی همان کمپیوتر
2. آدرس HTTPS

بعد از نصب و یک بار بازشدن کامل، برنامه آفلاین کار می‌کند.

## نصب روی کمپیوتر با Chrome / Edge

در همین پوشه اجرا کنید:

```bash
python3 -m http.server 8080
```

بعد در مرورگر باز کنید:

```text
http://localhost:8080
```

سپس از نوار آدرس یا منوی مرورگر گزینه **Install / نصب** را بزنید.

## انتقال اطلاعات قبلی

چون نسخه نصب‌شونده ممکن است در آدرس/Origin جدید اجرا شود، مرورگر آن را دیتابیس جداگانه حساب می‌کند.
برای حفظ اطلاعات:

1. از برنامه فعلی بکاپ کامل بگیرید.
2. نسخه PWA را نصب و باز کنید.
3. از تنظیمات، همان بکاپ را وارد کنید.

## آپدیت بعدی

برای آپدیت، فایل‌های همین پوشه را با نسخه جدید جایگزین کنید. اگر آدرس نصب یکی باشد، اطلاعات IndexedDB حفظ می‌شود.
